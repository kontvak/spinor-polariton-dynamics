# Формулы и методы расчёта

Единицы: мкм, пс, мэВ. 0D означает однородную двумерную плотность, а не амплитуду отдельной ловушечной моды. Основные коэффициенты и сценарии находятся в `config.yaml`; формулы — в `model.py`.

## Модели

- **M0:** прежнее скалярное поле и активный резервуар; потенциал `gC|ψ|² + gR(nR + ηPA)`.
- **M1:** поле, активный и неактивный резервуары; потенциал `gC|ψ|² + gA nA + gI nI`. Питание активного резервуара `QA = W nI`; `Pin = (γI+W)PA/W`, `gI/W = gR η`. Старое слагаемое `gR ηPA` здесь повторно не добавляется.
- **M2/M3:** две круговые компоненты, два активных и два неактивных резервуара. `Vσ = α1 nσ + α2 n−σ + gA nAσ + gI nIσ`; `−J ψ−σ` в энергетическом уравнении. M2 имеет J=0.
- Spin flip: `Γs(n−−n+)`, поэтому разность населённостей затухает как `exp(−2Γs t)`.
- При равной спиновой накачке `s = PA,tot/(2Pth)`, а не `PA,tot/Pth`. Плотность `nσ = |ψσ|²` отдельно не интегрируется.

## Интеграторы

0D: `scipy.integrate.solve_ivp`, DOP853, `rtol=2e-11`, `atol=2e-13`, `max_step=2 пс`; действительный вектор из Re/Im поля и резервуаров. Данные сохраняются на равномерной сетке, которая не равна адаптивному шагу.

RK4: все поля и резервуары продвигаются совместно; на четырёх стадиях пересчитываются плотности, потенциалы и связи. Скачок накачки разделяет интервалы интегрирования; последний шаг до скачка полностью использует старую накачку.

2D: кинетический FFT-полушаг → совместный локальный RK4 → FFT-полушаг. Множитель `exp[−iK k² Δt/(2ħ)]`, периодическая сетка без повторного правого конца. Полная схема второго порядка. Ускорение Numba выполняет тот же RK4 независимо в узлах, без `fastmath`, фильтрации или понижения точности. Поля complex128; резервуары float64. FFT применяется только к полям.

## Наблюдаемые и принятие результата

`θ = arg(ψ+ ψ−*)`; `IJ = (2J/ħ) Im(ψ−*ψ+)` положителен при притоке в +. `ωσ = −slope(arg ψσ)`. Фаза разворачивается только внутри непрерывных интервалов достаточного сигнала. Постоянная относительная фаза допускает постоянный ненулевой обменный ток.

Стационарность: размах и дрейф среднего плотностей <0.5%; в 2D дополнительно изменение нормированной плотности и поля с исключённой одной общей фазой <1%, два последовательных окна по 100 пс.

Период ищется по повторяющимся максимумам z и уточняется по возврату временного ряда без вычитания дрейфа. Проверяются n±, nA±, nI± и exp(iθ). Нужно ≥5 периодов в полном окне и ≥2 в каждой половине; согласие периодов 2%, амплитуд 5%, ошибка возврата плотностей и фазы <1%.

Общий баланс учитывает источник Pin и потери γC NC + γA NA + γI NI. Для M0 источник PA и суммы NC+NR. Баланс интегрируется; сохраняются абсолютная невязка и знаменатель. Затравка и поля не перенормируются, отрицательные резервуары не обрезаются.

Численное завершение, стационарность, периодичность и сходимость записываются отдельно. Неопределённые точки остаются в данных и на рисунках. Ссылки в новом отчёте относятся к предыдущим отчётам по названиям; траектории для сравнения рассчитаны заново.

## Сохранённый результат

Первоначальные серии F1–F5 выполнены; новая пространственная серия N3 рассматривается отдельно. фактические ошибки и время находятся в `diagnostic_summary.md`. F2: M0 выбирает q=−3, R1/R2 — +3. Контроль из поля M0 с nI=PA/W сохраняет q=−3 при обоих шагах в течение ещё 200 пс; он отделяет выбор аттрактора при включении от сохранения старого стационарного состояния. F5 теперь использует 105 точек, в том числе 78 новых по отношению к предыдущей версии рисунка. Основное окно 16000–18000 пс; неустановившиеся точки продлеваются до 36000/72000/144000 пс, а J=0.01159 — до 288000 пс. Для выбранных слабых циклов около 0.0068 и 0.0115 мэВ отдельно задан контроль на 70000–72000 пс (`scan_long_J`); две наиболее медленные точки потребовали 142000–144000 пс. Старые попытки анализа остаются в JSON. Дополнительно амплитуда цикла сравнивается с окном на 10000 пс раньше: изменение >5% означает незавершённый переход, даже если соседние короткие окна похожи на цикл.

`results/data/report_data.npz` — один переносимый набор 0D-траекторий и финальных полей/историй пяти F2-прогонов; массивы без pickle. Отдельные JSON содержат все точки, окна, ошибки и статусы. Подробные локальные `resolved_config.yaml`, `observables.npz`, `summary.json`, checkpoint и пространственные снимки лежат в игнорируемой `results/runs/`. `export_report_data()` обновляет переносимый набор после расчётов. 0D-метаданные разрешены при сохранении/экспорте: их хеш описывает код экспорта, не выдаётся за записанный до первоначального запуска хеш. Схема вычисления физического поля не менялась; ускоренный локальный шаг проверен против независимого NumPy-RK4.

## Досчёт и оформление F5

`scan_J_additional`, `scan_J_refined_ranges_meV`, `scan_refinement` и `scan_long_J` задают точки и времена. `run_spin_refinement()` переиспользует готовые траектории, продолжая именно их конечное состояние. Все основные точки имеют одинаковые начальные поля и пустые резервуары; не используется движение по J с подстановкой предыдущего аттрактора.

F5(a,b): для стационарных точек — среднее z за окно; для циклов — интеграл z по целому числу последних периодов, делённый на длительность. Концы интервала интерполируются линейно, `N=floor(длительность окна/T)`. Это убирает зависимость среднего от незавершённого последнего колебания; исходное арифметическое `mean_z` тоже сохранено, на рисунке — `plot_mean_z`. F5(c,d,f): отдельно A_z=(max z−min z)/2, без диапазонов, похожих на погрешности. F5(e): среднее [θ(t+T)−θ(t)]/T для циклов, наклон θ для стационарных/несвязанных компонент. Старый регрессионный `phase_slope` сохранён отдельно.

Ромбами обозначены два цикла с фазовой маской: минимум n_σ/(n_++n_−)<10⁻⁴. Для них проверяется возврат шести плотностей и нормированного вектора Стокса (S₁,S₂,z), ошибка <1%; относительная фаза через разрыв не разворачивается, дрейф не приписывается. Это `PERIODIC_PHASE_MASKED`, а не неподтверждённая периодичность. `run_phase_sampling_checks()` повторяет четыре пограничных окна с выборкой 0.05 вместо 0.5 пс, из точно сохранённого начального кадра окна.

Серые полосы убраны: цвета задают классификацию рассчитанных точек, не закрашенную область с известной границей. F5(b,d,f) увеличивают узкие интервалы. Открытые кружки в (b) — два контрольных продолжения состояния через скачок. `run_polarization_controls()` также меняет θ(0) на 1 и 2 рад по обе стороны; это отдельные эксперименты, не дополнительные основные точки.

`run_refinement_checks()` независимо повторяет выбранные `scan_J_check` с rtol=1e-11, atol=1e-13, max_step=1 пс. Сравниваются их фактические окна, классификация, плотности, короткие поля, амплитуды и периоды; результаты — `reference_checks.json`.

Чтобы переносимый NPZ оставался компактным, для F5 вне окон анализа и первых 200 пс оставлены точные кадры через 20 пс. Все окна итогового анализа и их сравнения с лагом сохранены с исходным шагом 0.5 пс; F1, F3 и четыре демонстрационных F4-траектории оставлены целиком. Времена и схема выборки записаны в `manifest_json` и ключах `*_archive_sampling`. Интерполяции или снижения точности полей при экспорте нет; полные исходные траектории и окна прежних попыток остаются в игнорируемой `results/runs/`. Все численные проверки выполняются на полных локальных данных, рисунки восстанавливаются из переносимого набора.

Для N3 совместный локальный RK4 ускорен Numba для обеих компонент сразу: все шесть полей пересчитываются на каждой стадии, без fastmath, перенормировки или клиппинга. Кинетика остаётся FFT-Strang. Первые шесть столбцов history прежние; далее NC+, NC−, NA+, NA−, NI+, NI−. В каждой компоненте на двух последовательных последних окнах по 100 пс требуются размах и дрейф средних трёх населённостей <0.5%, L2-изменение абсолютных карт конденсата/активного/неактивного резервуаров <1%. Кадры карт проверяются через 5 пс. Общую фазу для принятия N3 не проверяют.

Сходимость N3: каждая NC± и каждая абсолютная карта плотности должны отличаться менее чем на 1%; карты сравниваются в совпадающих узлах вложенных сеток без масштабирования или поворота. Баланс <10⁻³; край <10⁻⁴ и high-k <10⁻⁶ для каждой компоненты на последнем окне. Локальная z(x,y) маскируется при n++n−≤max(10⁻⁸ мкм⁻²,10⁻⁴ max(n++n−)) и сохраняется на D4. Близкие формы с различными населённостями являются допустимым результатом.

Серия N3 завершена при общем времени 2300 пс: все четыре прогона проходят установление и проверки сходимости. Итоги собраны из сохранённых контрольных точек без повторного интегрирования.

Новые рисунки находятся в `results/figures/report/`, PNG 160 мм, 300 dpi. Исходные F/D не перезаписываются. `make_report_figures()` использует только готовые массивы и обновляет блоки N3 в русском и английском отчётах из одной сводки. N3 использует общую абсолютную цветовую шкалу, а D4 — общую шкалу населённостей для обеих поляризаций накачки; серым отмечены последние два окна по 100 пс. `run_spatial_spin_suite(max_workers=4)` продолжает контрольные точки и по завершении сохраняет `spatial_spin.npz` и `N3_summary.json`; число процессов можно уменьшить. Час — ориентир, жёсткого отключения по времени нет.


## Определения метрик в отчёте

Для сравнения формы используются $\widehat n_\sigma=n_\sigma/N_\sigma$ и $\delta_{\rm shape}=\|\widehat n_+-\widehat n_-\|_{2,h}/\|\widehat n_+\|_{2,h}$, где $\|f\|_{2,h}=(\Delta x\Delta y\sum_{ij}|f_{ij}|^2)^{1/2}$. Область — все 256×256 мкм, без сдвига и поворота; знаменатель соответствует компоненте +. Для ε=0.3 это 5.55% после округления.

В проверках сходимости знаменатель — норма основного расчёта: $\delta_2(n_\sigma)=\|n_\sigma^{(c)}-\mathcal S n_\sigma^{(ref)}\|_{2,h_c}/\|\mathcal S n_\sigma^{(ref)}\|_{2,h_c}$. S выбирает совпадающие узлы контрольной сетки, а при сравнении шагов является тождественным оператором. Ошибка населённости равна $|N^{(c)}-N^{(ref)}|/|N^{(ref)}|$. В таблицах LaTeX эти доли умножаются на 100.

Полная схема Strang/RK4 имеет второй порядок по времени. При $J=\Gamma_{s,A}=\Gamma_{s,I}=0$ и нулевой компоненте − спиновая система переходит в скалярную модель с **двумя** резервуарами. Параметр $P_{A,\pm}$ — перенормированная внешняя накачка, а фактический поток из неактивного резервуара равен $Q_{A,\pm}=Wn_{I,\pm}$ и меняется при спиновой релаксации.


## Новая серия TE–TM: первый этап

B0: ε=0, J=β=0; A1: ε=0.3, J=β=0; T0: ε=0, J=0, β=0.0119 мэВ·мкм². Везде α2=−0.00024, остальные коэффициенты R1 прежние. Пятно exp(−r²/2.5²); кольцо exp[−(r−10)²/2.5²]. PA±=pPth(1±ε)f, Pin=cP PA. Подбор общего p=4/8/16 относится к наличию конденсата, не к контрасту или стационарности. Начало каждого режима независимое: ψ±=sqrt(10⁻⁴ f/2), пустые резервуары.

L=256 мкм, 512², dx=0.5 мкм, dt=0.025 пс; исходно 3000 пс, продления по 1000 до 6000. Поля complex128, резервуары float64 на Intel Arc. В k-пространстве B01=β(kx−iky)², B10=B01*, диагональ Kk². Полушаг U(τ)=exp(−iKk²τ/ℏ)[cos(u)I−i(τ/ℏ)sinc(u)B], u=βk²τ/ℏ, τ=dt/2, sinc=sin(u)/u. В k=0 нет TE–TM; деления на k² нет. Между U-полушагами — совместный локальный RK4 шести полей с −J в гамильтониане. Соседние U(dt/2) объединяются в U(dt); на каждом выводе состояние восстановлено на физический момент времени. Порядок всей схемы — второй.

S0=n++n−, S1=2Re(ψ+*ψ−), S2=2Im(ψ+*ψ−), S3=n+−n− — ненормированные плотности. si=Si/S0. Старое соглашение явно названо legacy_s1/legacy_s2; legacy_s2=−S2/S0, θ=arg ψ+−arg ψ− сохранена. Ток в «+» от J равен −J S2/ℏ. Старые классификаторы используют прежние нормированные переменные. Динамика от переименования не меняется.

Каждые 0.25 пс сохраняются индивидуальные населённости, интегралы Стокса и балансов; угловые S0/S3 по 72 секторам — через 1 пс, полные диагностические поля — через 5 пс в скользящем дисковом буфере. Для двух последовательных окон: размах/дрейф каждой населённости <0.5%, L2-изменения шести карт плотности <1%; изменения S1/S2/S3 нормируются на ||S0|| и должны быть <0.01. При J или β≠0 дополнительно разрешена только одна общая фазовая подгонка спинора.

Период сначала оценивается по нескольким интегральным и угловым наблюдаемым, затем независимо проверяется по обоим окнам. Каждое окно ≥max(200,5T) пс. Период/амплитуда между окнами отличаются <1%; обе плотности, все резервуары и все три карты Стокса должны повторяться через T с ошибкой <1%. После ночной проверки для дробного лага применяется локальный восьмиточечный полином по плотностям и ненормированным Stokes, с шеститочечной проверкой (расхождение <0.002); комплексные поля не интерполируются. Почти постоянные наблюдаемые не усиливаются до веса больших колебаний. Исходная линейная интерполяция оказалась недостаточна для циклов 54–56 пс при кадрах через 5 пс. При слишком короткой истории или превышении предела времени — UNRESOLVED. Периоды менее 50 пс на текущей частоте карт не принимаются без отдельного уточнения вывода. Сравнения имеют общий поздний интервал; вращения карт и независимой подгонки компонент нет.

Проверяются отдельно интегралы источника конденсата и всех частиц с RK4-квадратурой: остаток <10⁻³. Внешняя полоса 0.1L: вес <10⁻⁵; спектр |kx| или |ky|>0.7kNy: вес <10⁻⁶. Для затухшего почти нулевого поля относительный краевой вес сохраняется как диагностика, но не доказывает существования конденсата. Никакого клиппинга, фильтра, поглотителя или температурного прерывания нет.

### Обновлённый подбор накачки после остановки p=4

Вместо 4/8/16 и общего p для обеих геометрий выполняется линейный поиск на замороженной нулевой ветви. При psi=0: I_sum=Pin_sum/(gammaI+W), I_diff=Pin_diff/(gammaI+W+2GammaI); A_sum=W I_sum/gammaA, A_diff=W I_diff/(gammaA+2GammaA). Компоненты восстанавливаются как (sum±diff)/2. При B0 эта ветвь точно совпадает с прежним скалярным линейным оператором; старые ориентиры: пятно 10.9375–11, кольцо 2.625–2.640625. alpha1/alpha2 в линейной задаче отсутствуют.

Кинетика+TE–TM — прежняя точная матричная FFT-экспонента; локальный линейный шаг — точная диагональная экспонента при J=0. Поле перенормируется через 1 пс, накапливаются логарифмы множителей амплитуды. При beta=0 компоненты нормируются независимо, чтобы не потерять порог слабейшей; при beta≠0 — совместно. Широкая непрерывная затравка из 24 волн одинакова на разных сетках и предназначена для поиска ведущей моды, а не заменяет радиальную начальную подготовку нелинейных запусков.

### Проверка complex64 и чувствительности

`TorchSpinStepper`: `execution.precision` = `complex64` или прежний по умолчанию `complex128`. В первом случае поля/FFT — complex64, резервуары и локальный RK4 — float32; суммы населённостей, интегральных источников и накопители балансов — float64. `audit_report3_precision`: для каждого из 14 эталонов берутся три распределённых по доступному скользящему буферу состояния. Из каждого выполняется блок 10 пс в обеих точностях. Отдельный double-блок с гладким возмущением относительного масштаба 1e-5 оценивает усиление возмущений: G = E_end/E_start. E — RMS трёх относительных L2-норм: спинора после одной общей фазовой подгонки, активного и неактивного резервуаров. Направления возмущений воспроизводимы; это направленные конечные разности, не полный Якобиан и не гарантированная верхняя граница. Невязка перезапуска double относительно сохранённого эталона записывается отдельно. Разность single/double включает начальное округление состояния при приведении к float32.

Риск = максимум ошибок населённостей, плотностей и взвешенных нормированных Стоксов, умноженный на max(1,G). По нему выбираются два полных повтора complex64: наиболее рискованное переходное кольцо и периодическое пятно. Для выбранных случаев усиление перепроверяется при возмущении 5e-6; изменение >5% даёт WARN. Начало каждого полного повтора — исходная радиальная затравка при t=0, финал — 3000 пс; промежуточной подмены состояния эталоном нет.

Карты интерполируются восьмиточечным полиномом; фазы компонент независимо не подгоняются. RMS разности нормированных Стоксов взвешивается S0 эталона на маске S0>1e-3 max(S0). При повторной обработке precision-серии амплитуды двух окон сравниваются только в значимых каналах: в физических относительных единицах размах должен превышать max(1e-6, 0.01 наибольшего размаха). ## Диагностический пространственный J-скан

`make_spot_J_diagnostic()` читает сохранённые результаты очереди без интегрирования. Z=(N₊−N₋)/(N₊+N₋), A_Z=(max Z−min Z)/2. Средние и скорость фазы усредняются по двум принятым окнам; для периодических состояний в каждом окне берётся целое число измеренных циклов. Θ=−unwrap arg ∫(S₁+iS₂)d²r; средняя скорость равна [Θ(b)−Θ(a)]/(b−a), не наклону произвольного короткого фрагмента. Локально проверяется θ=arg(ψ₊ψ₋*) в пяти указанных в JSON точках.

Статус режима требует исходного PASS стационарности/периодичности полных карт. Для вращения — ненулевое число оборотов интегральной фазы за цикл в обоих окнах (>0.5 по модулю), локальные фазы совершают более одного оборота за окно. Для ограниченных колебаний — размах фаз<2π, интегральное число оборотов за цикл<0.05, A_Z>0.001. Для фиксированной фазы — исходная STATIONARY и локальный размах<0.01 рад. При доле слабой компоненты<10⁻³ или приращении фазы между кадрами>0.8π локальный фазовый тест маскируется. Полные проверки/окна сохраняются в `spot_J_diagnostic.json`; это классификация наблюдавшихся состояний, не математическая граница притяжения.
