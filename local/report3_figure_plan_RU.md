## 2. Общие правила для новых рисунков

- На картах координаты x, y в мкм, одинаковый масштаб по обеим осям. Выбирать область показа так, чтобы конденсат был хорошо виден.
- Для сравниваемых компонент плотности — общая абсолютная цветовая шкала. Для пятна и кольца допускаются разные шкалы.
- Для нормированных Стоксов — единая шкала от −1 до 1. Области недостаточной плотности маскировать, а не окрашивать как нулевую поляризацию.
- В подписи различать мгновенный снимок, среднее по времени и стационарное состояние. Указывать время либо интервал.
- В подписи приводить накачку, J, β, геометрию и смысл панелей. Остальные общие коэффициенты можно отнести к таблице параметров.
- На самих рисунках использовать физические названия. Коды A1/T0/C1 ниже нужны только для выбора данных.
- Сравнения влияния связи выполнять при одинаковой накачке и подготовке внутри каждой геометрии. Разные геометрии имеют разные рабочие накачки: p = 13.8 для пятна и p = 3.3 для кольца.

Не добавлять диагностические кривые и таблицы ошибок в основные изображения. Число панелей определяется содержанием, а не стремлением поместить всю серию на один лист.

## 3. Глава 2 — плотности двух компонент

### N1. Пятно и кольцо: пространственные плотности

**Основа:** F2_circular_component_densities.png; исходные данные A1 для обеих геометрий.

**Состав:** четыре карты, 2 × 2:

- верхняя строка — пятно, n₊ и n₋;
- нижняя строка — кольцо, n₊ и n₋.

Условия: неравенство накачки ε = 0.3, J = β = 0, α₂ = −0.1α₁. Общая цветовая шкала внутри каждой строки. Тонким контуром обозначить половину максимума накачки.

**Назначение:** показать форму конденсата и различие интенсивностей двух круговых компонент. Само изображение пространственного состояния является достаточной задачей этого рисунка.

В подписи привести N₊, N₋ и Z для показанного состояния или окна. Постоянство плотностей не называть постоянством всей поляризации.

### N2. Дополнительный эффект α₂ — резервный рисунок

**Основа:** F3_cross_spin_density_comparison.png; A0 и A1.

**Состав:** две панели с радиальными плотностями: пятно и кольцо. Цвет различает компоненты; сплошная/штриховая линия — α₂ = 0 и α₂ = −0.1α₁. Остальные параметры одинаковы.

**Назначение:** отделить влияние α₂ от различия накачки компонент.

Кривые не увеличивать искусственно ради заметного расхождения. Если они почти совпадают, это прямо отметить. Точную величину малого эффекта не заявлять без соответствующей оценки погрешности. Для меняющихся карт использовать сопоставимые средние по поздним циклам.

Подготовленный рисунок оставить кандидатом: при окончательной сборке можно заменить одним предложением в тексте. Отдельную большую серию ради него не назначать.

## 4. Глава 4 — TE–TM и совместное действие связей

### N3. TE–TM для гауссова пятна

**Основа:** F4_TE_TM_spot.png; данные T0 пятна.

**Состав:** две панели:

1. Полная плотность S₀ = n₊ + n₋.
2. Круговая поляризация s₃ = (n₊ − n₋)/(n₊ + n₋).

Условия: равная накачка, ε = 0, J = 0, β = βref. Использовать позднее проверенное состояние. Показать контур накачки.

**Назначение:** одновременно показать, где сосредоточена плотность и как TE–TM создаёт области противоположной круговой поляризации.

Две отдельные карты n₊ и n₋ здесь не обязательны: они уже представлены в главе 2. В подписи отметить симметричную начальную подготовку и сравнение с соответствующим β = 0 контролем; отдельную почти пустую карту s₃ = 0 не добавлять.

### N4. TE–TM для кольцевой накачки

**Основа:** F5_TE_TM_ring.png; актуальные данные T0 кольца.

**Состав:** те же две панели и тот же порядок, что в N3: S₀ и s₃. Показать два контура половины максимума кольцевой накачки.

Использовать актуальный снимок при 6000 пс, если он соответствует выбранной сопоставимой серии. Момент явно указать в подписи.

**Назначение:** показать пространственную поляризацию кольцевого конденсата.

Важно: T0-кольцо не принято как состояние со стационарной поляризацией. Подпись должна говорить о снимке при указанном времени. Не смешивать его с прежним радиально подготовленным T0 при 3000 пс и не описывать различие карт как одну временную траекторию, если начальные условия различались.

### N5. Как угловая поляризация пятна зависит от β

**Основа:** левая панель F6_TE_TM_angular_response.png, T0-пятно и соответствующий β = 0 контроль.

**Состав:** один график:

- горизонтальная ось — β/βref = 0, 0.5, 1, 2;
- вертикальная — Q₂, мера второй угловой гармоники круговой поляризации.

Показывать четыре точки. Соединяющая линия служит ориентиром, не результатом отдельной аппроксимации. Не добавлять вторую панель кольца.

**Назначение:** количественно подтвердить усиление угловой структуры при увеличении TE–TM-связи.

В подписи кратко определить Q₂, область измерения и позднее окно. Если показывается временной разброс, назвать его именно временным разбросом. Для всех точек использовать одну пространственную квадратуру.

### N6. Совместное действие связей: динамика пятна

**Основа:** F8_spot_coupling_comparison.png; A1, T1, J1, C1 пятна.

**Состав:** один временной график 2 Re C₂(t) при одинаковом ε = 0.3:

- без J и TE–TM;
- только TE–TM;
- только J;
- J и TE–TM вместе.

Если две контрольные линии практически совпадают с нулём, отметить их совпадение в подписи; не разводить их искусственно.

Показать примерно три поздних периода, чтобы различие кривых читалось легче, чем на длинной последовательности колебаний. Начало интервала одинаковое для сравниваемых траекторий; не сдвигать каждую кривую независимо ради совпадения максимумов.

**Назначение:** показать временную динамику угловой поляризации и её изменение при добавлении J.

Подпись должна пояснять, что 2 Re C₂ — косинусная составляющая второй угловой гармоники. Это не локальный параметр Стокса и не полный модуль Q₂. Не называть изменение этой величины доказательством жёсткого вращения всей карты без дополнительной проверки.

### N7. Совместное действие связей: угловая структура кольца

**Основа:** F8_ring_coupling_comparison.png; сопоставимые A1, T1, J1, C1 кольца.

**Состав:** один график s₃(φ), четыре режима как в N6. Угол в градусах, от −180° до 180°. Использовать одну и ту же область радиального интегрирования.

**Назначение:** показать изменение среднего уровня круговой поляризации и её угловой структуры при разных связях.

Для периодического T1 указать момент или выбранную фазу цикла; его профиль не представлять как неизменный во времени. Если показаны собственные поздние времена разных запусков, перечислить их в подписи. Стационарные и периодические профили могут находиться на одном рисунке, если это ясно обозначено.

Использовать общую полярную квадратуру, как в обновлённом F8. Дополнительные графики производных, спектров гармоник и невязок здесь не нужны.

### Определения для N5–N7

В формулах ниже S₀ = n₊ + n₋, S₃ = n₊ − n₋, а R — выбранная кольцевая область анализа:

\[
C_2(t)=
\frac{\int_R S_3(r,\varphi,t)e^{-2i\varphi}\,d^2r}
{\int_R S_0(r,\varphi,t)\,d^2r},
\qquad Q_2(t)=2|C_2(t)|.
\]

Q₂ характеризует только вторую угловую гармонику, а не всю неоднородность поляризации.

Для N7 s₃(φ) получается как отношение радиальных интегралов S₃ и S₀ в соответствующем направлении/угловом секторе, с элементом площади r dr dφ. Это не невзвешенное среднее локальных s₃.

### N10. Три режима J на сфере Пуанкаре — новый рисунок

**Источник:** те же однородные траектории, которые использованы в рис. 4–5 report_spin(2).pdf. Нужны комплексные поля либо n₊, n₋ и относительная фаза θ. При отсутствии этих данных восстановить только необходимые три расчёта после сверки параметров.

**Состав:** три небольшие сферы рядом:

1. J = 5 мкэВ — бегущая относительная фаза.
2. J = 6.5 мкэВ — ограниченные фазовые колебания.
3. J = 10 мкэВ — фиксированное состояние.

На каждой сфере оси s₁, s₂, s₃, одинаковый ракурс и масштаб. Для периодических случаев показать один полный поздний цикл, начало и стрелку направления. Цвет можно использовать для нормированного времени внутри цикла; фактический период указать в подписи. Фиксированный режим изображается точкой.

**Назначение:** объединить плотности и фазу в одно изображение состояния поляризации и наглядно сопоставить три режима.

Прежние графики θ(t) сохраняются: одна замкнутая линия на сфере не показывает число фазовых оборотов. Не рисовать условные окружности вместо рассчитанных траекторий.

### N11. Поляризация в центре 2D-пятна на сфере Пуанкаре — новый рисунок

**Точка наблюдения только одна: (x,y) = (0,0). Другие точки и пространственное усреднение не добавлять.**

**Источник:** T1 и C1 пятна, одинаковые ε = 0.3, накачка и начальная подготовка.

**Состав:** две сферы рядом:

1. TE–TM, J = 0.
2. TE–TM и J = 0.010 мэВ.

В обоих случаях β = βref. В каждой панели строить мгновенный локальный вектор s(0,0,t) за один полный поздний цикл соответствующего режима. Использовать общий поздний начальный момент, затем собственную длительность цикла каждого режима. Указать оба интервала и периоды; одинаковый цвет означает одинаковую долю выбранного цикла.

**Назначение:** показать, как добавление J меняет движение поляризации именно в центре пятна.

Для C1 начальный момент согласовать с картами N8. Центр уже отмечен на этой карте; дополнительная карта расположения точек не нужна.

Если в центре одного из режимов поляризация почти постоянна, честно показать точку или малую траекторию. Не заменять центр более эффектной точкой и не увеличивать малое движение отдельным масштабированием координат сферы.

T0 с равной накачкой не подставлять вместо T1: иначе вместе с J изменится ε.

### Единые определения для главы 5

\[
S_0=|\psi_+|^2+|\psi_-|^2,\quad
S_1=2\operatorname{Re}(\psi_+^*\psi_-),\quad
S_2=2\operatorname{Im}(\psi_+^*\psi_-),\quad
S_3=|\psi_+|^2-|\psi_-|^2,
\qquad s_i=S_i/S_0.
\]

Использовать новое соглашение о знаке s₂, согласованное в методах. Для старых 0D-данных не брать прежнюю переменную legacy_s2 без преобразования.

Эквивалентное восстановление:
\[
s_1=\sqrt{1-z^2}\cos\theta,\qquad
s_2=-\sqrt{1-z^2}\sin\theta,\qquad s_3=z.
\]

Для ненулевого локального когерентного поля проверяется s₁²+s₂²+s₃² ≈ 1. Дополнительную принудительную нормировку длины вектора не применять. Полюс сферы допустим при исчезновении одной компоненты, пока S₀ остаётся ненулевым.

Для сфер брать мгновенные значения без усреднения по времени. Если сохранённая временная выборка слишком редкая для гладкой траектории, уточнить вывод локальных наблюдаемых на коротком позднем интервале; не заменять его художественным сглаживанием.
